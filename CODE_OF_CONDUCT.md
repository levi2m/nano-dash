# Code of conduct

Be respectful and keep it about the project. Disagree with the idea, not the person. No harassment, insults, or sharing other people's private information (including GPS tracks of rides that are not yours).

The maintainer may edit or remove comments, issues and pull requests that break this, and may block repeat offenders. To report a problem, use [GitHub's private report form](https://github.com/levi2m/nano-dash/security/advisories/new) and say it is a conduct issue.
